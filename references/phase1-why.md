# Phase 1 — WHY: Growth Market Strategy

Establishes WHY a market is worth entering. Run tools in sequence; each output feeds the next.

---

## Tool 1: Goal & Growth Gap

**Purpose**: Set the financial ambition and separate current business growth from new market initiatives.

### Output Format

**Growth Waterfall Table**

| Growth Layer | Initiative | 3-Year Revenue Target |
|-------------|-----------|----------------------|
| GI N | [Market / Initiative Name] | $XM–$YM |
| ... | ... | ... |
| BAU Growth | Current business optimisation | ~$XM+ |

Stack from bottom (BAU) to top (highest GI). Each GI is a named market or initiative.

**Gap Analysis Table**

### Key Rule
Never jump to market recommendations without first completing the Growth Gap. The waterfall creates the financial frame that validates SPAN/FAN later.

## Tool 7: Cross SWOT → Strategic Areas

**Purpose**: IBM's Cross SWOT goes beyond listing S/W/O/T. It crosses them to produce four strategic areas, each with Top 3 Actions.

### Step 1: Define S/W/O/T codes

| Code | Strength | Code | Weakness |
|------|---------|------|---------|
| S1 | ... | W1 | ... |
| S2 | ... | W2 | ... |

| Code | Opportunity | Code | Threat |
|------|------------|------|--------|
| O1 | ... | T1 | ... |
| O2 | ... | T2 | ... |

### Step 2: Cross SWOT Matrix (mandatory — not optional)

| Quadrant | IBM Name | S/W × O/T Mapping | Core Strategy | Top 3 Actions |
|---------|----------|-------------------|--------------|---------------|
| 1 | **Business Opportunity** | S × O: Use strengths to capture opportunities | | 1. 2. 3. |
| 2 | **Market Creation** | S × T: Use strengths to turn threats into market creation | | 1. 2. 3. |
| 3 | **Transformation** | W × O: Fix weaknesses to capture opportunities | | 1. 2. 3. |
| 4 | **Business Risk** | W × T: Protect weaknesses from threats | | 1. 2. 3. |

**Format note**: Each quadrant entry lists the specific S/W/O/T codes being crossed (e.g. "S1/S3/S4 × O1/O3"). This prevents vague strategy statements.
